# Custom AlertDialog Programmatically

Source code for the blog post: [AlertDialog in Android — The Complete Guide](https://pcsalt.com/android/alertdialog-android-complete-guide/)

Demonstrates building a custom AlertDialog layout entirely in code — no XML layout files for the dialog content.

## What's covered

- Creating EditText and LinearLayout programmatically
- Building a login dialog with username and password fields
- Using AlertDialog.Builder with programmatic views

## Tech stack

- Kotlin
- Material 3
- ViewBinding
- minSdk 34, targetSdk 36
